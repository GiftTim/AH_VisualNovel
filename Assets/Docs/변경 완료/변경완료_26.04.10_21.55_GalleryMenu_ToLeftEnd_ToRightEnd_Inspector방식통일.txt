1. 변경 전 코드
================================================================

  ─────────────────────────────────────────────────
  [ ConstructNavBar() ]
  ─────────────────────────────────────────────────

    private void ConstructNavBar()
    {
        ...
        LeftEndButton.onClick.AddListener(ToLeftEnd);    // ← 코드로 등록
        RightEndButton.onClick.AddListener(ToRightEnd);  // ← 코드로 등록
        ArrangeNavBarOrder();
        UpdateNavBarWindow();
    }

  ─────────────────────────────────────────────────
  [ ToLeftEnd / ToRightEnd ]
  ─────────────────────────────────────────────────

    private void ToLeftEnd()    // ← private
    {
        windowStart = 1;
        UpdateNavBarWindow();
        LoadPage(1);
        StartCoroutine(SelectPageButtonNextFrame(1));
    }

    private void ToRightEnd()   // ← private
    {
        int lastWindowStart = ((maxPages - 1) / PAGE_BUTTON_LIMIT) * PAGE_BUTTON_LIMIT + 1;
        windowStart = lastWindowStart;
        UpdateNavBarWindow();
        LoadPage(maxPages);
        StartCoroutine(SelectPageButtonNextFrame(maxPages));
    }

3. 변경 후 작동 흐름
================================================================

  [ onClick 등록 방식 ]

    변경 전: ConstructNavBar()에서 코드로 AddListener 등록
    변경 후: Unity Inspector의 LeftEndButton / RightEndButton OnClick()에서
             GalleryMenu.ToLeftEnd / GalleryMenu.ToRightEnd 직접 연결

  [ 호출 흐름 (Inspector 방식) ]

    사용자가 LeftEndButton 클릭
      → Unity EventSystem이 Inspector에 등록된 OnClick() 실행
      → GalleryMenu.ToLeftEnd() 호출
      → windowStart = 1 → UpdateNavBarWindow() → LoadPage(1)
         → SelectPageButtonNextFrame(1)

    사용자가 RightEndButton 클릭
      → Unity EventSystem이 Inspector에 등록된 OnClick() 실행
      → GalleryMenu.ToRightEnd() 호출
      → lastWindowStart 계산 → UpdateNavBarWindow() → LoadPage(maxPages)
         → SelectPageButtonNextFrame(maxPages)

  [ 기존 ToNextPage / ToPreviousPage와 동일한 패턴 ]

    public void ToNextPage()     → Inspector OnClick 연결
    public void ToPreviousPage() → Inspector OnClick 연결
    public void ToLeftEnd()      → Inspector OnClick 연결  ← 이번 변경
    public void ToRightEnd()     → Inspector OnClick 연결  ← 이번 변경

  ※ Inspector에서 연결 작업 필요:
      LeftEndButton  의 OnClick() → GalleryMenu.ToLeftEnd
      RightEndButton 의 OnClick() → GalleryMenu.ToRightEnd
