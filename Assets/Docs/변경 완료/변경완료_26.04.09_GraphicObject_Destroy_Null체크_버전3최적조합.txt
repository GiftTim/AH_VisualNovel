c. 변경 후 작동 흐름
----------------------------------------------------

  [ 정상 FadeOut 흐름 ]
    Fading(target=0) 실행
      → while 루프: 매 프레임 opacity를 0으로 감소
        → yield return null (다음 프레임 대기)
          → renderer null 체크 → 유효하면 루프 계속
            → opacity == 0 도달 → 루프 종료
              → Destroy() 호출
                → currentGraphic 정리
                → oldGraphics에서 this 제거 (Remove 1회 순회)
                → renderer != null → Object.Destroy(renderer.gameObject)

  [ 외부 파괴 시 FadeOut 흐름 ]
    Fading(target=0) 실행
      → yield return null (다음 프레임 대기)
        → [외부] renderer.gameObject 파괴
          → renderer null 체크 → null 확인 → yield break (코루틴 즉시 종료)
            → Destroy() 미호출 → MissingReferenceException 발생 없음

  [ Destroy() 직접 호출 시 renderer가 이미 파괴된 경우 ]
    Destroy() 호출
      → currentGraphic 정리
      → oldGraphics.Remove(this)
      → renderer == null 확인 → Object.Destroy 호출 생략
        → 예외 없이 안전하게 종료
