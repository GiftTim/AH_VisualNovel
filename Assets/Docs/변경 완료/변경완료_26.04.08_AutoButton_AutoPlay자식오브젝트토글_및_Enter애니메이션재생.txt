3. 변경 후 코드
----------------------------------------------------

  [ AutoReader.cs - 변경 후 ]

  //[SerializeField] private TextMeshProUGUI statusText;
  [SerializeField] private GameObject autoPlayIndicator;
  [HideInInspector] public bool allowToggle = true;

  public void Enable()
  {
      if (isOn)
          return;

      if (autoPlayIndicator != null)
      {
          autoPlayIndicator.SetActive(true);
          autoPlayIndicator.GetComponent<Animator>().Play("Enter");
      }

      co_running = StartCoroutine(AutoRead());
  }

  public void Disable()
  {
      if (!isOn)
          return;

      StopCoroutine(co_running);
      skip = false;
      co_running = null;
      //statusText.text = string.Empty;

      if (autoPlayIndicator != null)
          autoPlayIndicator.SetActive(false);
  }

4. 작동 흐름
----------------------------------------------------

  [ Auto ON 흐름 ]
    1. 유저가 Auto 버튼 클릭
    2. Toggle_Auto() 호출 → isOn == false이므로 Enable() 호출
    3. Enable() 내부:
       a. autoPlayIndicator.SetActive(true) → Auto-Play 자식 오브젝트 활성화
       b. autoPlayIndicator.GetComponent<Animator>().Play("Enter") → Enter 애니메이션 재생
       c. StartCoroutine(AutoRead()) → 자동 읽기 코루틴 시작
    4. Auto-Play 오브젝트가 화면에 표시되며 Enter 애니메이션이 재생됨

  [ Auto OFF 흐름 ]
    1. 유저가 Auto 버튼 재클릭
    2. Toggle_Auto() 호출 → isOn == true이므로 Disable() 호출
    3. Disable() 내부:
       a. StopCoroutine(co_running) → 자동 읽기 코루틴 정지
       b. skip = false, co_running = null → 상태 초기화
       c. autoPlayIndicator.SetActive(false) → Auto-Play 자식 오브젝트 비활성화
    4. Auto-Play 오브젝트가 화면에서 사라짐 (Animator도 오브젝트 꺼지며 자동 정지)

  [ Skip → Auto OFF 경로 ]
    - Toggle_Skip() → Disable() 경로를 통해도 autoPlayIndicator.SetActive(false) 실행됨
    - 어느 경로로 Disable이 호출되어도 시각 처리 누락 없음
