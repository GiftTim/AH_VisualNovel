  │ ① 경로탐색 (BFS)      │ ★☆☆☆☆  │ 완전독립│ 노드 기반 이동  │
  │ ② 오디오 시스템       │ ★☆☆☆☆  │ 완전독립│ 효과음/배경음   │

c. 현재 상황 및 코드
================================================================

  [ 현재 프로젝트 환경 ]
  - Unity 버전   : 6000.3.8f1 (Unity 6)
  - URP 버전     : 17.3.0
  - Strategy game.unity : 완전히 비어있음 (기본 설정만 존재)
  - 기존 의존 패키지 : DOTween 없음, SoftMaskForUGUI 없음

  [ GameDispatchLike 환경 ]
  - URP 버전     : 14.0.11  ← 현재 프로젝트보다 낮음
  - DOTween      : 사용 중 (애니메이션 트위닝)
  - SoftMaskForUGUI : 사용 중 (UI 마스킹)
  - 아키텍처     : MVC 패턴 + Singleton + Factory + ScriptableObject

  [ 레포 주요 폴더 구조 ]
  Assets/
  ├── Scripts/
  │   ├── Controllers/     - 게임 로직 (GameManager, DayManager 등)
  │   ├── Model/           - 데이터 모델 (CharacterUnit, MissionUnit 등)
  │   │   ├── Databases/   - CharacterDatabase, CharacterLevelDatabase
  │   │   └── Factories/   - FactoryCharacterUnit, FactoryGameState
  │   ├── View/            - UI 관련 (Calendar, Day, Guild, MainMenu 뷰)
  │   ├── SaveSystem/      - 저장/불러오기
  │   ├── PathFinder/      - BFS 경로탐색 (PathFinderManager, Node)
  │   ├── Utils/           - Singleton, StringUtils, ClassExtensions 등
  │   └── General/         - SoundManager
  ├── SO/
  │   ├── Character/       - BaseCharacterSO (캐릭터 설정)
  │   ├── Days/            - DaySO (하루 설정)
  │   ├── Game/            - GameStateSO, GameSettingsSO
  │   └── Missions/        - MissionSO (임무 설정)
  ├── Prefabs/             - 캐릭터/UI/네비게이션 프리팹
  ├── TurnBaseBattle/      - 별도 턴제 전투 씬+스크립트
  └── Sprites/             - 스프라이트 이미지

  [ 시스템 의존 관계도 ]

  GameManager ← 모든 것의 허브
       ├── DayManager → DayCharacterManager, DayMissionManager
       ├── CharacterDatabase ← FactoryCharacterUnit
       ├── GameState ← Guild, MissionUnit, CharacterUnit
       └── SaveSystem

  PathFinder  → 완전 독립 (아무것도 의존 안 함)
  SoundManager → 완전 독립 (UnityEngine만 사용)
  Utils       → 완전 독립

d. 요구한 기능을 만들기 위해서 어떤 식으로 생성하거나 변경해야 하는지
================================================================

  [ 통합 방식: 선택적 복사 + 어댑터 패턴 ]

  GameDispatchLike를 통째로 합치지 않고,
  원하는 시스템의 스크립트/SO/프리팹만 선택해
  현재 프로젝트의 별도 폴더(Assets/StrategyGame/)에 넣는다.

  ─────────────────────────────────────────
  STEP 1. 레포 클론 (로컬 임시 경로)
  ─────────────────────────────────────────
  git clone https://github.com/ViniciusChrisosthemos/GameDispatchLike.git
  → 현재 Unity 프로젝트 외부 임시 폴더에 클론

  ─────────────────────────────────────────
  STEP 2. 대상 폴더 생성
  ─────────────────────────────────────────
  현재 프로젝트에 아래 구조로 폴더 생성:
  Assets/StrategyGame/
  ├── Scripts/
  │   ├── PathFinder/
  │   ├── Utils/
  │   ├── Audio/
  │   ├── Character/     (선택 시)
  │   ├── Mission/       (선택 시)
  │   ├── Day/           (선택 시)
  │   └── SaveSystem/    (선택 시)
  ├── SO/
  │   ├── Character/
  │   ├── Missions/
  │   └── Game/
  └── Prefabs/

  ─────────────────────────────────────────
  STEP 3. 시스템별 복사 (선택한 것만)
  ─────────────────────────────────────────
  시스템별로 필요한 파일만 위 폴더에 복사.
  (하단 f. 진행 순서에서 구체적 파일 목록 제시)

  ─────────────────────────────────────────
  STEP 4. 패키지 의존성 처리
  ─────────────────────────────────────────
  - DOTween: Unity Asset Store에서 무료 버전 다운로드 설치
    (또는 Package Manager → Add from git URL)
  - SoftMaskForUGUI: UI 시스템 선택 시에만 필요
    (https://github.com/mob-sakai/SoftMaskForUGUI)
  - 현재 프로젝트에 없는 의존성만 설치

  ─────────────────────────────────────────
  STEP 5. URP 호환성 수정
  ─────────────────────────────────────────
  URP 14 → URP 17 변경사항 대응:
  - 셰이더 파일이 있다면 Edit → Render Pipeline → Upgrade 실행
  - 머티리얼 URP 업그레이드 (Unity 자동 변환 도구 사용)
  - URP 14에서 쓰던 deprecated API는 Unity 6 방식으로 수정

  ─────────────────────────────────────────
  STEP 6. 컴파일 에러 수정
  ─────────────────────────────────────────
  - 선택한 시스템과 연결된 참조 중 복사하지 않은 클래스 제거
  - namespace 충돌 시 Assets/StrategyGame/ 전용 namespace 적용
  - Unity 6 API 변경 부분 수정 (FindObjectOfType → FindFirstObjectByType 등)

  ─────────────────────────────────────────
  STEP 7. Strategy game 씬 구성
  ─────────────────────────────────────────
  - 필요한 Manager 오브젝트 씬에 배치
  - ScriptableObject 인스턴스 생성 및 Inspector 연결
  - 프리팹 배치 및 UI Canvas 설정

e. 다른 방법들 중에서 왜 d의 방식으로 만든 것인지
================================================================

  [ 검토한 방법들 ]

  방법 1: Git Submodule로 전체 통합
  ─────────────────────────────────
  - GameDispatchLike를 서브모듈로 추가해 전체 포함
  - 단점: Unity 버전/URP 버전 충돌로 씬 파일 전체 파괴 가능
          불필요한 파일(Test 씬, 타 게임 에셋) 전부 포함됨
          두 프로젝트의 Package 버전이 달라 manifest.json 충돌
  → ❌ 채택 안 함

  방법 2: 전체 에셋 복사
  ──────────────────────
  - 레포 Assets 폴더 전체를 현재 프로젝트에 복사
  - 단점: 불필요한 에셋(UI, 미사용 씬 등)까지 전부 포함
          GUID 충돌 가능성 (특히 TextMesh Pro, URP 관련)
          DOTween/SoftMask 버전 충돌로 컴파일 에러 다수 발생 가능
  → ❌ 채택 안 함

  방법 3: 선택적 복사 (채택) ✅
  ──────────────────────────────
  - 원하는 시스템의 스크립트만 선별적으로 복사
  - 장점: 최소한의 파일만 포함, 충돌 범위 최소화
          불필요한 의존성 제거 가능
          단계별로 진행하며 각 시스템 검증 가능
          현재 VisualNovel 시스템과 완전 분리
  → ✅ 채택

  방법 4: 처음부터 직접 작성 (레포 참고만)
  ──────────────────────────────────────────
  - GameDispatchLike 코드를 참고해 처음부터 새로 작성
  - 장점: 완전히 현재 프로젝트에 최적화됨
  - 단점: 시간이 매우 많이 걸림, 레포의 핵심 로직 재구현 필요
  → 추후 개선 단계로 고려 (지금은 아님)

h. 주의할 점
================================================================

  ① URP 버전 차이 (가장 중요)
  ─────────────────────────────
  - GameDispatchLike의 머티리얼/셰이더는 URP 14 기준
  - 현재 프로젝트는 URP 17 (Unity 6)
  - 셰이더 파일을 복사하면 렌더링 오류가 발생할 수 있음
  - 대응: Edit → Rendering → Materials → Convert... 자동 변환 도구 사용
  - 커스텀 셰이더(.shader, .hlsl)는 수동으로 URP 17 API에 맞게 수정 필요

  ② GUID 충돌 위험
  ─────────────────
  - TextMesh Pro, URP 관련 에셋은 두 프로젝트에 공통으로 존재
  - GameDispatchLike의 TextMesh Pro 폴더는 절대 복사하지 말 것
  - SO(ScriptableObject)의 GUID가 충돌하면 참조가 깨짐
  - 대응: SO는 복사 후 Unity에서 새로 인스턴스를 생성하는 것이 안전

  ③ DOTween 필요 여부 확인
  ──────────────────────────
  - 복사한 스크립트 중 DOTween 사용 여부 먼저 확인
  - 사용하는 스크립트가 있으면: Asset Store에서 DOTween 무료 버전 설치
  - 없으면: 설치 불필요

  ④ 스크립트 참조 깨짐 방지
  ───────────────────────────
  - 일부 시스템만 복사하면 복사하지 않은 클래스를 참조하는 부분에서 에러 발생
  - 대응: 필요 없는 참조는 주석 처리 또는 임시 stub 클래스 생성
  - 절대 컴파일 에러 상태로 Unity를 끄지 말 것 (씬 파일 손상 가능)

  ⑤ Unity 6 API 변경사항
  ─────────────────────────
  - FindObjectOfType<T>() → FindFirstObjectByType<T>() (deprecated 경고)
  - OnDrawGizmos, 일부 Physics API 변경됨
  - 복사 후 콘솔 Warning/Error 목록 전수 확인 필요

  ⑥ 작업 전 반드시 Git Commit
  ─────────────────────────────
