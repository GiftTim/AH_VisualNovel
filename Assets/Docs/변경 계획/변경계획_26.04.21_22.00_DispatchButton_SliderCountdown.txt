b. 요구한 기능
----------------------------------------------------

  - 대상 씬: Assets/Scenes/StrategyGame.unity
  - 참고: https://github.com/ViniciusChrisosthemos/GameDispatchLike.git

  요구 사항:
    · 버튼(Button)에 부착하는 스크립트
    · 버튼을 클릭하면 Slider의 value가 1에서 0으로 서서히 감소
    · 감소에 걸리는 시간(초)을 Inspector에서 직접 입력할 수 있음
    · 예) duration = 10f → 10초에 걸쳐 Slider가 1→0으로 줄어듦

  연출 목적 (파견 게임 맥락):
    · Dispatch(파견) 버튼을 누르면 미션 타이머가 동작하는 연출
    · Slider가 꽉 찬(1) 상태 → 버튼 클릭 → Slider가 서서히 빠짐(0)
      = 남은 시간이 줄어드는 시각적 피드백

d. 요구한 기능을 만들기 위해서 어떤 식으로 생성하거나 변경해야 하는지
----------------------------------------------------

  [ 방식: 신규 스크립트 SliderCountdown.cs 생성 (Coroutine 방식) ]

  저장 경로:
    Assets/Scripts/StrategyGame/Core/UI/SliderCountdown.cs

  스크립트 내용 (예시):
  -------------------------------------------------------
  using System.Collections;
  using UnityEngine;
  using UnityEngine.UI;

  /// <summary>
  /// 버튼에 부착.
  /// StartCountdown()을 Button OnClick에 연결하면
  /// Slider value가 1에서 0으로 duration 초에 걸쳐 감소한다.
  /// </summary>
  public class SliderCountdown : MonoBehaviour
  {
      [Header("연결 대상")]
      [SerializeField] private Slider _slider;

      [Header("타이머 설정")]
      [SerializeField] private float _duration = 10f;   // Inspector에서 직접 입력

      private Coroutine _countdownCoroutine;

      /// <summary>
      /// 버튼 OnClick에 연결할 메서드.
      /// 이미 진행 중인 카운트다운이 있으면 초기화 후 재시작.
      /// </summary>
      public void StartCountdown()
      {
          if (_countdownCoroutine != null)
              StopCoroutine(_countdownCoroutine);

          _countdownCoroutine = StartCoroutine(CountdownCoroutine());
      }

      private IEnumerator CountdownCoroutine()
      {
          if (_slider == null) yield break;

          _slider.value = 1f;
          float elapsed = 0f;

          while (elapsed < _duration)
          {
              elapsed += Time.deltaTime;
              _slider.value = 1f - Mathf.Clamp01(elapsed / _duration);
              yield return null;
          }

          _slider.value = 0f;
          _countdownCoroutine = null;
      }
  }
  -------------------------------------------------------

  Inspector 연결 방법:
    1. Button GameObject에 SliderCountdown 컴포넌트 추가
    2. Inspector에서 _slider 필드에 대상 Slider 오브젝트 드래그 연결
    3. Inspector에서 _duration 값을 원하는 초 단위로 직접 입력 (예: 10)
    4. Button 컴포넌트의 OnClick() 이벤트에 SliderCountdown.StartCountdown 연결

e. 다른 방법들 중에서 왜 d의 방식으로 만든 것인지
----------------------------------------------------

  방법 A (기각): DOTween - slider.DOValue(0f, duration)
    - 코드가 간결하고 이미 프로젝트에 DOTween이 도입되어 있음
    - 단점:
        · 진행 중 강제 중단, 완료 콜백 등 확장 시 DOTween Sequence/Kill
          관리가 복잡해짐
        · Slider.value를 직접 제어하는 Coroutine 대비 내부 동작을
          추적하기 어려워 디버깅이 불편함
        · DOTween이 없는 환경(패키지 제거 등)에서는 동작 불가

  방법 B (기각): MissionDispatcher.cs 에 타이머 로직 추가
    - 단점:
        · MissionDispatcher는 캐릭터 이동/경로 담당 → UI 타이머 추가 시
          단일 책임 원칙(SRP) 위반
        · 하나의 스팟에 Slider가 여러 개인 상황 등 확장 시 대응 어려움

  방법 C (채택, d의 방식): 신규 SliderCountdown.cs — Coroutine 방식
    - 장점:
        · 버튼 하나에 하나의 컴포넌트로 독립적으로 동작
          → 재사용성 높음 (여러 버튼에 각각 붙여서 사용 가능)
        · duration을 Inspector에서 직접 입력 가능 → 기획 변경에 유연
        · Coroutine으로 매 프레임 elapsed 추적
          → 완료 콜백, 일시정지, 재시작 등 확장이 직관적
        · 외부 라이브러리(DOTween) 의존 없음
        · 이미 CharacterAgent.cs에서 동일한 Coroutine 이동 패턴 사용 중
          → 프로젝트 코드 스타일과 일관성 유지

  → 방법 C 채택.
    독립성·재사용성·확장성 모두에서 가장 적합한 방식.

    - d항의 코드 그대로 작성

  Step 2. Unity 에디터 - 컴포넌트 부착
    - StrategyGame 씬에서 대상 Button GameObject 선택
    - Add Component → SliderCountdown

  Step 3. Unity 에디터 - Inspector 연결
    - Slider 필드: 대상 Slider 오브젝트 드래그 연결
    - Duration 필드: 원하는 시간(초) 직접 입력

  Step 4. Unity 에디터 - OnClick 연결
    - Button 컴포넌트의 On Click () 이벤트 섹션에서 [+] 클릭
    - 오브젝트란에 SliderCountdown이 붙은 GameObject 드래그
    - 함수 선택: SliderCountdown → StartCountdown()

  Step 5. 테스트
    - Play 모드 진입
    - 버튼 클릭 → Slider가 1에서 0으로 duration 초에 걸쳐 감소하는지 확인
    - 버튼을 중간에 다시 클릭 → Slider가 1로 초기화 후 재카운트 시작 확인
    - duration 값을 바꾸어 속도 변화 확인

h. 주의할 점
----------------------------------------------------

  1. Slider 초기값 확인
     - Slider의 Min Value = 0, Max Value = 1 로 설정되어 있어야 함
     - 카운트다운 시작 시 value를 강제로 1f로 설정하므로
       Slider의 시작 상태(인스펙터의 Value 초기값)는 무관

  2. 버튼 재클릭 시 재시작 동작
     - 현재 설계: 진행 중 재클릭 → 기존 코루틴 중단 후 1f부터 재시작
     - 재클릭을 막으려면 버튼의 Interactable을 false로 전환하는
       로직을 추가해야 함 (현재 설계에는 포함되지 않음)

  3. 오브젝트 비활성화 시 코루틴 자동 중단
     - Button 오브젝트가 SetActive(false)되면 코루틴이 자동 중단됨
     - 재활성화 시 Slider.value는 중단된 지점에서 멈춰 있으므로
       필요 시 OnEnable()에서 Slider.value = 1f 로 초기화 추가 고려

  4. Time.timeScale 영향
     - Time.deltaTime을 사용하므로 timeScale = 0이면 카운트다운이 멈춤
     - 일시정지 기능이 필요한 경우 의도된 동작이나,
       일시정지 무관하게 흐르길 원하면 Time.unscaledDeltaTime으로 교체

  5. DOTween 충돌 없음
     - SliderCountdown.cs는 DOTween을 사용하지 않으므로
       기존 DOTween 사용 스크립트(HoverEffect, Spot)와 충돌 없음
