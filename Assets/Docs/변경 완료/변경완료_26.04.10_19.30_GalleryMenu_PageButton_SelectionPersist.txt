================================================================
작동 흐름
================================================================

[ 갤러리 진입 시 ]
  Open() 호출
  → Initialize() (최초 1회)
      → ConstructNavBar() : 페이지 버튼 생성
      → LoadPage(1) : selectedPage = 1
      → StartCoroutine(SelectPageButtonNextFrame(1))
          → 현재 프레임: 버튼 클릭 이벤트 처리 완료 대기
          → 다음 프레임: SelectPageButton(1) 호출
              → EventSystem.SetSelectedGameObject(pageButtons[0])
              → 1번 버튼 하이라이트 확정

[ nextButton 클릭 시 ]
  OnPointerDown : EventSystem → nextButton 선택
  OnPointerClick : ToNextPage() 실행
      → windowStart += 3
      → UpdateNavBarWindow() : 버튼 텍스트/이벤트 갱신
      → LoadPage(windowStart) : selectedPage = windowStart
      → StartCoroutine(SelectPageButtonNextFrame(windowStart))
          → 현재 프레임: Unity 이벤트 처리 완료 (nextButton 기준 정리됨)
          → 다음 프레임: SelectPageButton(windowStart) 호출
              → 새 윈도우의 첫 번째 페이지 버튼 하이라이트 확정

[ 빈 공간 클릭 시 ]
  Unity EventSystem → currentSelectedGameObject = null
  → 다음 Update() 프레임에서 감지
      → initialized == true, previewPanel 닫혀있음
      → EventSystem.currentSelectedGameObject == null 조건 충족
      → SelectPageButton(selectedPage) 호출
      → 현재 페이지 버튼 하이라이트 복원

[ previewPanel 열려있는 동안 ]
  Update() 실행
  → previewPanelCG.isVisible == true (alpha > 0 또는 페이드인 중)
  → return 으로 조기 종료 → 페이지 버튼에 간섭 없음

[ previewPanel 닫기 (HidePreviewImage) ]
  Hide() 호출 → 페이드 아웃 시작
  SelectPageButton(selectedPage) 즉시 호출 → 복원
  (페이드 중에는 Update() return으로 간섭 없음, 완전히 닫히면 Update()가 유지)
