b. 요구한 기능
================================================================

  DayManager의 이벤트(OnMissionAvailable, OnTimeUpdated, OnDayEnd)를
  Unity Hierarchy의 UI 오브젝트와 연결하여 다음 흐름을 화면에서 확인한다:

  ① 임무 등장 시 → 임무 카드(UIMissionController) UI 생성
  ② 임무 카드 클릭 → 임무 정보 패널(UIMissionManagerViewController) 열림
  ③ 팀 수락 버튼 클릭 → DayManager.AcceptMission() → DayManager.StartMission() 호출
  ④ 임무 완료/실패 → DayManager.ClaimMission() 호출 → 카드 제거
  ⑤ 하루 종료 → DayReport 결과 화면 표시

d. 구현 방향
================================================================

  레퍼런스 레포의 3계층 구조를 그대로 채택한다:
    Layer 1: UIDayManager       — DayManager 이벤트 수신 + UI 오케스트레이션
    Layer 2: UIMissionController — 개별 임무 카드 (프리팹)
    Layer 3: UIMissionManagerViewController — 임무 상세 패널

  레퍼런스 레포와의 차이점 (이 프로젝트에 맞게 조정):
    ① SoundManager 의존 제거 (AudioManager 공유 구조로 추후 연결)
    ② SpriteFill(커스텀 컴포넌트) → Unity 기본 Image.fillAmount로 대체
    ③ AnimatePathController(맵 애니메이션) → 1단계에서 생략, 콜백 직접 호출
    ④ 팀 선택 UI(UISelectTeamViewController) → 1단계에서 버튼 1개로 단순화
       (캐릭터 없이 테스트 중이므로 빈 Team으로 즉시 수락)

e. 다른 방법들과 d를 선택한 이유
================================================================

  [방법 A] Inspector에서 UnityEvent에 직접 함수 드래그 연결
    → OnMissionAvailable 파라미터가 List<MissionUnit>이라 Inspector 연결 불가.
    → 채택 안 함.

  [방법 B] 레퍼런스 레포 스크립트를 그대로 복사
    → SpriteFill, SoundManager.Instance 등 미존재 의존성으로 컴파일 에러 발생.
    → 채택 안 함.

  [방법 C] UIDayManager + 간소화된 UIMissionController + 간소화된 패널 ← 채택
    → 레퍼런스 레포의 구조·연결 방식을 따르되 외부 의존성 제거.
    → 현재 테스트(캐릭터 없음) 환경에서 동작 가능.
    → 나중에 팀 선택 UI, 애니메이션 등 기능을 점진적으로 추가하기 용이.

h. 주의할 점
================================================================

  ① 테스트 단계에서 AcceptMission에 빈 Team 전달
     → 현재 _runOnStart는 캐릭터 없이 StartDay(1, [])를 호출한다.
     → AcceptMission(mission, new Team())으로 빈 팀을 넘기면
       DayCharacterManager.HandleTeamAcceptMission()이 빈 Members를 순회하므로
       NullReference 없이 통과한다. (Members가 null이 아닌 빈 List인지 Team 생성자 확인 필요)

  ② IPointerClickHandler 동작 조건
     → UIMissionController에 IPointerClickHandler를 구현할 경우
       Canvas 하위에 EventSystem 오브젝트가 씬에 존재해야 클릭이 인식된다.
     → Canvas 생성 시 Unity가 자동으로 EventSystem을 추가하므로 확인만 할 것.

  ③ TimerImage fillAmount 방향
     → Image Type: Filled, Fill Method: Radial 360, Fill Origin: Top으로 설정해야
       시계처럼 줄어드는 타이머 표현이 가능하다.
     → fillAmount = 1 - GetTimeLeftToMakeAction() (0이 가득 찬 상태)

  ④ UIMissionManagerViewController.Open() 호출 시 이전 리스너 누적 방지
     → _btnAccept.onClick.RemoveAllListeners() 후 AddListener()를 호출해야
       카드를 여러 번 클릭해도 콜백이 중복 등록되지 않는다.

  ⑤ WaitingToBeAccepted 상태가 아닌 임무 클릭 처리
     → Completed 상태: ClaimMission() 호출로 즉시 처리
     → InProgress/Accepted 상태: 패널을 열지 않거나 진행 상태만 표시
     → 1단계에서는 WaitingToBeAccepted일 때만 패널을 열어도 충분.
