1. 요구한 기능
================================================================

  [ 건물 구조 ]
  ┌────────────────────────────────────────────────────────────┐
  │ HQ        — 타입 고정. 모든 캐릭터 출발/귀환 거점         │
  │ Building  — Idle에서 시작. 미션 사이클 진행               │
  └────────────────────────────────────────────────────────────┘

  [ Building 상태 흐름 ]
  Idle ──[미션 발생]──► Incident ──[수락]──► Selected
                                  └─[미수락/만료]──► Unselected
  Selected ──[임무 완료]──► Completed ──► (Idle 또는 유지, 추후 결정)

  [ 핵심 규칙 ]
  - 모든 길은 HQ로 통한다
    캐릭터 : HQ → 목표 Building → HQ
  - HQ와 각 Building 사이에 정적 연결선(지도 UI) 항상 표시
  - 미션 수락(Selected) 시 해당 경로를 LineRenderer로 강조 표시
  - (나중에) 캐릭터 오브젝트가 LineRenderer 경로를 따라 이동

  [ 이번 구현 범위 ]
  ① HQ 타입 보호 (SetType 호출해도 변경 안 됨)
  ② Idle→Incident→Selected/Unselected→Completed 흐름 정리
  ③ HQ ↔ Building 정적 연결선: UI Image (PathFinderManager 기존 기능)
  ④ Selected 시 HQ→Building 경로를 LineRenderer로 시각화
  ⑤ 미션 종료(Completed or Unselected) 시 LineRenderer 숨김
  ⑥ 캐릭터 이동은 이번 범위에 포함하지 않음 (나중에 별도 작업)

  using System.Collections.Generic;
  using UnityEngine;

  public class PathLineRenderer : MonoBehaviour
  {
      [SerializeField] LineRenderer _lineRenderer;
      [SerializeField] Camera _uiCamera;   // Screen Space - Camera 시 사용

      void Awake()
      {
          if (_lineRenderer == null)
              _lineRenderer = GetComponent<LineRenderer>();
          _lineRenderer.enabled = false;
      }

      public void ShowPath(List<Spot> path)
      {
          _lineRenderer.positionCount = path.Count;
          for (int i = 0; i < path.Count; i++)
              _lineRenderer.SetPosition(i, GetWorldPos(path[i]));
          _lineRenderer.enabled = true;
      }

      public void Hide()
      {
          _lineRenderer.enabled = false;
      }

      Vector3 GetWorldPos(Spot spot)
      {
          // Canvas가 Screen Space - Overlay 인 경우
          var screenPos = RectTransformUtility.WorldToScreenPoint(
              null, spot.transform.position);
          float z = Mathf.Abs(_uiCamera != null
              ? _uiCamera.nearClipPlane + 0.1f
              : Camera.main.nearClipPlane + 0.1f);
          var cam = _uiCamera != null ? _uiCamera : Camera.main;
          return cam.ScreenToWorldPoint(new Vector3(screenPos.x, screenPos.y, z));
      }
  }

7. 주의할 점 (h)
================================================================

  ① 좌표계 확인 필수 (가장 중요)
     Canvas 모드에 따라 GetWorldPos() 내 좌표 변환 방식이 달라진다.
     - Screen Space - Overlay:
       RectTransformUtility.WorldToScreenPoint(null, spot.transform.position)
       → Camera.main.ScreenToWorldPoint()
     - Screen Space - Camera:
       spot.transform.position 이 이미 월드 좌표이므로 변환 불필요
     씬의 Canvas Inspector에서 Render Mode 확인 후 코드 분기 결정.

  ② LineRenderer Sorting Layer
     LineRenderer는 기본적으로 Default Layer 에 렌더링됨.
     Canvas UI 위에 보이려면:
     - LineRenderer의 sortingLayerName을 UI 레이어보다 높게 설정
     - 또는 Canvas의 Canvas 컴포넌트 → Override Sorting 체크 후
       Order In Layer 조정

  ③ HQ의 _neighbors 설정
     PathFinderManager.GetPath()는 BFS로 _neighbors를 탐색함.
     HQ에서 각 Building까지 경로가 연결되려면
     Inspector에서 HQ의 _neighbors에 인접 Spot들이 등록되어 있어야 한다.
     (또는 Building의 _neighbors에 HQ 등록 — BFS는 방향 그래프)

  ④ _hq 필드 반드시 연결
     PathFinderManager의 _hq 슬롯에 HQ Spot을 반드시 연결해야
     ActivateMissionPath()가 올바른 출발점에서 경로를 계산한다.

  ⑤ 동시 미션 처리
     현재 MissionManager는 단일 활성 경로만 지원.
     동시에 여러 캐릭터가 다른 Building으로 이동하는 케이스는
     _pathLineRenderer를 List로 확장하는 작업이 추후 필요.

  ⑥ Completed 이후 상태
     Completed → Idle 복귀 여부는 게임 디자인에 따라 결정 필요.
     현재는 Completed에서 멈추도록 구현.
