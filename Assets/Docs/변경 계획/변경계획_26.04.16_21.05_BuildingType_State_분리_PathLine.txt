1. 요구한 기능
================================================================

  [ 변경 포인트 요약 ]
  ① 건물 타입(BuildingType)과 상태(BuildingState)를 분리된 enum으로 관리
  ② HQ는 씬에 1개만 존재할 수 있음 (강제 검증)
  ③ 연결선 항상 표시 제거 — 경로는 미션 이동 중에만 LineRenderer로 표시
     - 캐릭터 HQ → Building 이동 시 표시
     - 캐릭터 Building → HQ 귀환 시 표시
     - 그 외엔 경로선 없음

  [ 건물 구조 ]
  ┌──────────────────────────────────────────────────────────────┐
  │ BuildingType.HQ       — 씬에 1개 고정. 타입/상태 변경 없음  │
  │ BuildingType.Building — 복수 존재. 아래 상태 흐름에 따름    │
  └──────────────────────────────────────────────────────────────┘

  [ Building 상태 흐름 ]
  Idle ──[미션 발생]──► Incident ──[수락]──► Selected
                                  └─[만료/미수락]──► Unselected
  Selected ──[임무 완료]──► Completed

  [ 경로 표시 흐름 ]
  미션 수락 (Selected)
    → PathLineRenderer.ShowPath( HQ → Building 경로 )

  임무 완료 (Completed) — 귀환 이동
    → PathLineRenderer.ShowPath( Building → HQ 경로 )

  귀환 도착
    → PathLineRenderer.Hide()

  public class MissionManager : MonoBehaviour
  {
      [SerializeField] PathFinderManager _pathFinder;

      // 미션 발생 (외부에서 호출)
      public void OnMissionOccurred(Spot target)
          => target.SetState(BuildingState.Incident);

      // 미션 수락 → 경로 표시 (HQ → Building)
      public void OnMissionAccepted(Spot target)
      {
          target.SetState(BuildingState.Selected);
          _pathFinder.ShowMissionPath(target);
      }

      // 미션 만료/미수락
      public void OnMissionExpired(Spot target)
      {
          target.SetState(BuildingState.Unselected);
          _pathFinder.HidePath();
      }

      // 임무 완료 → 귀환 경로 표시 (Building → HQ)
      public void OnMissionCompleted(Spot target)
      {
          target.SetState(BuildingState.Completed);
          _pathFinder.ShowReturnPath(target);
      }

      // 귀환 도착 → 경로 숨김
      public void OnCharacterReturned()
          => _pathFinder.HidePath();
  }

7. 주의할 점 (h)
================================================================

  ① Spot Inspector 재설정 필수
     Spot.cs 구조가 바뀌면 기존 Inspector에 설정된
     SpotType, SpotVisualConfig 값이 날아간다.
     수정 후 씬 내 모든 Spot 오브젝트의
     BuildingType, BuildingState, _hqVisual/_buildingVisuals를
     다시 Inspector에서 설정해야 한다.

  ② HQ 단일 존재 검증은 Runtime 전용
     Awake()의 FindObjectsByType은 런타임에만 동작.
     에디터에서 실수로 HQ를 2개 두는 것을 막으려면
     별도 Editor 스크립트(CustomEditor or OnValidate)가 필요하나
     이번 범위에서는 포함하지 않음.
     테스트 시 HQ가 1개인지 직접 확인 필요.

  ③ Canvas Render Mode 확인
     PathLineRenderer의 ToWorldPos()는 Canvas 모드에 따라 달라짐.
     씬의 Canvas Inspector → Render Mode 확인 후
     Screen Space - Overlay 인지 Screen Space - Camera 인지에 맞게
     ToWorldPos 내부 분기를 결정해야 한다.

  ④ LineRenderer Sorting Layer
     LineRenderer는 기본 Default Layer 렌더링.
     UI 요소(Spot 아이콘 등) 위에 보이려면
     LineRenderer의 Sorting Layer / Order In Layer 조정 필요.
     또는 씬의 Camera 설정에 따라 Z값 조정 필요.

  ⑤ GetPath() 경로 없음 처리
     _hq와 target 사이 _neighbors 연결이 없으면
     GetPath()는 빈 리스트를 반환함.
     ShowMissionPath / ShowReturnPath 에서
     path.Count == 0 일 때 LineRenderer를 표시하지 않는
     방어 처리가 필요함.

  ⑥ BuildingState.Completed 이후 처리
     Completed → Idle 복귀 여부는 게임 디자인 결정 사항.
     현재는 Completed에서 멈추고 별도 호출 없이 상태 유지.
     추후 미션 사이클 재시작 로직 추가 시 MissionManager 확장.
