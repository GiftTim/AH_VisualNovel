d. 변경 방식
================================================================================

  - 기존 코드 로직은 일절 변경하지 않음
  - 주석만 추가 (한국어)
  - 추가 위치:
      1) 클래스 선언 바로 위  → 클래스 역할 설명 블록 주석 (/* ... */)
      2) 각 필드/프로퍼티 옆 또는 위  → 인라인 주석 (//)
      3) 각 메서드 선언 바로 위  → 메서드 설명 블록 주석
      4) 복잡한 로직 라인 옆  → 인라인 주석

  - 주석 언어: 한국어 (사용자 프로젝트 관례 따름)
  - Unity 표준 XML 문서 주석(///<summary>) 은 사용하지 않음
    → 에디터에서 툴팁이 필요한 수준이 아닌, 코드 가독성 향상이 목적이므로


================================================================================
e. 다른 방법과 비교 / 이 방식을 선택한 이유
================================================================================

  [방법 A] XML 문서 주석 (/// <summary>)
  - 장점: IntelliSense 툴팁 지원, 자동 문서화 도구(DocFX 등) 연동 가능
  - 단점: 형식이 장황하고, 비주얼 노벨 같은 단일 팀 프로젝트에서 오버엔지니어링
  - 제외 이유: 목적이 "처음 보는 사람이 코드를 읽을 때 이해"이므로 불필요

  [방법 B] 코드 리팩토링 + 주석 (변수명 개선 포함)
  - 장점: 이름 자체가 설명이 되므로 주석 의존도 줄어듦
  - 단점: 기존 코드를 변경하므로 동작 검증 필요, 사용자 요구 범위 초과
  - 제외 이유: 요구사항이 "주석만 추가"이므로 로직 변경 없이 진행

  [방법 C] 별도 Wiki/문서 파일로만 정리
  - 장점: 코드 파일이 깔끔하게 유지됨
  - 단점: 코드와 문서가 분리되어 있어 코드 읽는 중 맥락을 잃기 쉬움
  - 제외 이유: 코드 내부에서 직접 확인 가능한 것이 가독성에 더 효과적

  ★ 채택: 방법 D (인라인 한국어 주석)
  - 코드 로직 불변, 가독성 최대화
  - 클래스/메서드 블록 + 필드 인라인 조합으로 계층적 설명
  - 사용자 기존 코드 스타일(한국어 주석)과 일관성 유지

h. 주의할 점
================================================================================

  1. 코드 로직 변경 없음
     - 주석 추가만 수행. 변수명, 메서드 시그니처, 실행 순서 모두 유지.

  2. 기존 영문 주석 처리
     - VN_Configuration.cs의 //Display Settings, //Text Settings 등
       기존 영문 주석은 한국어 주석으로 교체 또는 병기.

  3. SerializeField 어트리뷰트 위치
     - 주석을 [SerializeField] 위에 달면 어트리뷰트가 인스펙터에서
       주석으로 분리되어 보이지 않음. 문제 없음.

  4. GalleryMenu.cs - ArrangeNavBarOrder()
     - nextButton, RightEndButton을 강제로 마지막 자식으로 이동
     - Instantiate로 버튼을 동적 생성하면 부모의 자식 순서가 바뀌기 때문
     - 주석에 이 이유를 명확히 기술할 것

  5. VNGameSave - GetConversationData의 파일기반/인라인 분기
     - conversation.file != string.Empty 인지 여부로 분기
     - 파일 기반은 파일명+인덱스만 저장 → 용량 절약이 목적
     - 인라인은 전체 라인을 저장 → 동적으로 생성된 대화에 사용
     - 이 차이를 주석에 명확히 기술할 것

  6. VNGameSave - SetVariableData의 타입 switch
     - System.Boolean / System.Int32 / System.Single / System.String
     - C# 타입 전체 이름 문자열 (typeof(bool).ToString() 과 동일)
     - 주석에 각 타입이 어떤 C# 타입인지 명시할 것
