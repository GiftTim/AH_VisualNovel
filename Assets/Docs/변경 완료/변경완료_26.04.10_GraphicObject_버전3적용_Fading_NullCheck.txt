3. 변경 후 작동 흐름
----------------------------------------------------

  [ Destroy() 흐름 ]

    1. layer.currentGraphic 이 자신(this)의 renderer를 가리키고 있으면
       → layer.currentGraphic = null 로 참조 해제

    2. layer.oldGraphics.Remove(this)
       → this 기준 동일성 비교(참조 동일)로 1회 순회 후 제거.
          oldGraphics에 없어도 조용히 무시 (bool 반환 버려짐).
          renderer가 Unity null 상태여도 다른 오브젝트와 오매칭 없음.

    3. renderer != null 이면 GameObject를 Unity에서 파괴.


  [ Fading() null 체크 흐름 ]

    1. while 루프 내에서 매 프레임 opacity를 MoveTowards로 이동.
    2. yield return null 로 1프레임 대기.
    3. 프레임 재개 직후 renderer == null 체크.
       → null이면 yield break로 코루틴 즉시 종료.
          (외부에서 renderer가 파괴된 경우 MissingReferenceException 방지)
    4. null이 아니면 while 조건 재평가 후 계속 진행.
    5. 루프 종료 후 co_fadingIn / co_fadingOut = null 정리.
    6. target == 0 이면 Destroy() 호출, 아니면 DestroyBackgroundGraphicsOnLayer().
