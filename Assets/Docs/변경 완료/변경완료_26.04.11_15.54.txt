c. 작동 흐름
────────────────────────────────────────

 [선택 시 흐름]
 1. 유저가 Dropdown에서 옵션 선택 (예: "창모드 (1280 x 720)")
 2. OnValueChanged → SetDisplayResolution() 호출
 3. index == 0이면 ExclusiveFullScreen 1920x1080 적용
 4. index != 0이면:
      rawText = "창모드 (1280 x 720)"
      resolution = ExtractResolution(rawText)  →  "1280 x 720"
      values = ["1280 ", " 720"]
      width=1280, height=720 파싱 성공
      Screen.SetResolution(1280, 720, Windowed)
 5. config.display_resolution = "창모드 (1280 x 720)"  (전체 텍스트 저장)

 [저장 및 복원 흐름]
 1. 앱 종료 시 VN_Configuration.Save() → vnconfig.cfg에 JSON 저장
      display_resolution: "창모드 (1280 x 720)"
 2. 다음 실행 시 LoadConfig() → VN_Configuration.Load() 호출
 3. Dropdown 옵션을 순회하며 optionText == display_resolution 직접 비교
      "창모드 (1280 x 720)" == "창모드 (1280 x 720)" → 일치 → res_index = 해당 index
 4. ui.resolutions.value = res_index → SetDisplayResolution() 호출 → 복원 완료


 [주의사항]
  - 기존에 vnconfig.cfg가 저장되어 있으면 구 형식("1920 x 1080")과 불일치하여
    항상 index 0(전체창)으로 복원됨.
  - 기존 파일 삭제 또는 초기화 필요.
  - Inspector에서 ui.resolutions(TMP_Dropdown)의 OnValueChanged에
    ConfigMenu.SetDisplayResolution이 연결되어 있는지 별도 확인 필요.
