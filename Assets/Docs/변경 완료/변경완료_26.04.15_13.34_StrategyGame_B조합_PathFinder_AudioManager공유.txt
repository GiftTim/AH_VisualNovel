3. 작동 흐름
================================================================

  [ PathFinder 흐름 ]
  1. Start(): [Nodes] 하위 자식을 순회해 Node 목록 수집
  2. Update(): I 키 입력 → GetPath(Node(0), Node(2)) 호출
  3. GetPath(): BFS로 Node(0) → Node(1) → Node(2) 경로 탐색
  4. Console: "Path 3" 출력 (3개 노드 = Node(0), Node(1), Node(2))
  5. OnDrawGizmos(): 에디터에서 Cyan 선(전체 연결), Red 선(현재 경로) 표시

  [ AudioManager 흐름 ]
  - Main Menu → Strategy game 씬 전환 시:
      Main Menu의 AudioManager.instance 유지 (DontDestroyOnLoad)
      Strategy game의 Audio Manager 복사본 → DestroyImmediate로 자동 제거
  - Strategy game 직접 실행 시:
      Strategy game의 Audio Manager가 싱글턴으로 동작
  - AudioManager.instance.PlayTrack("경로", channel, loop) → BGM 재생
  - AudioManager.instance.PlaySoundEffect("경로", volume) → SFX 재생

4. 주의할 점
================================================================

  ① Unity Editor 재컴파일 필수
  ─────────────────────────────────────────────────────────────
  PathFinderManager.cs / Node.cs 신규 파일 추가 후
  Unity Editor가 자동 컴파일한다. Console 에러 0 확인 후 씬 사용.

  ② Unity가 .meta GUID를 재생성하는 경우
  ─────────────────────────────────────────────────────────────
  Unity Editor가 기존 .meta를 무시하고 새 GUID를 생성하면
  씬 파일의 스크립트 참조(guid: c3d4e5f... / d4e5f678...)가 깨진다.
  이 경우 Inspector에서 직접 PathFinderManager.cs / Node.cs를 드래그하여
  Missing Script를 재연결해야 한다.

  ③ AudioMixerGroup 3개 연결 Inspector에서 확인
  ─────────────────────────────────────────────────────────────
  씬 파일에 YAML로 연결했으나, Unity가 씬을 열 때 올바르게
  로드됐는지 Inspector에서 3개 필드가 모두 연결된 것을 눈으로 확인.
  미연결 시 ConfigMenu SetMusicVolume() 호출에서 NullReferenceException.

  ④ PathFinder 테스트: Play → I 키 → "Path 3" Console 확인
  ─────────────────────────────────────────────────────────────
  _debug = true, Origin = Node(0), Destiny = Node(2) 이미 씬에 설정됨.
  Play 모드에서 I 키를 누르면 Console에 "Path 3"이 출력되어야 정상.

  ⑤ DontDestroyOnLoad 중복 경고 (에디터 환경)
  ─────────────────────────────────────────────────────────────
  에디터에서 Play/Stop 반복 시 AudioManager 중복 경고가 Console에
  출력될 수 있으나, 빌드 실행 시에는 발생하지 않는다. 무시 가능.
