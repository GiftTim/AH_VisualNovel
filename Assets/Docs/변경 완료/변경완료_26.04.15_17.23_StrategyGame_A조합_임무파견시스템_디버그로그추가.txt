3. 동작 흐름
================================================================

  Play 시작
    └─ DayManager.StartDay() 호출
         └─ DayLoopCoroutine() 시작

  경과 시간 60초 도달 (DayDurationInSeconds=120, 임무 1개 → interval=60s)
    └─ DayMissionManager.UpdateMissions()
         └─ spawnTime 도달 감지
              └─ Console: "[DayMissionManager] 임무 등장: 테스트 임무 (spawnTime=60.0s)"
              └─ _newMissionsCallback 발행 → DayManager.HandleNewMissions()
                   └─ OnMissionAvailable 이벤트 발행 (UI 연결 시 수신 가능)

  수락 없이 TimeToAccept(40초) 초과 시
    └─ MissionUnit.OnMissioMiss 발행
         └─ DayMissionManager.HandleMissionLost()
              └─ Console: "[DayMissionManager] 임무 소멸(Lost): 테스트 임무"
              └─ OnMissionMiss 발행 → DayManager.HandleMissionMiss()

  HasMissions() = false 확정 후
    └─ WaitUntil(AllCharacterInBase) 대기
         └─ Console: "[DayManager] 하루 종료 → OnDayEnd 발행"
              └─ OnDayEnd 이벤트 발행

4. 주의할 점
================================================================

  ① 이 Debug.Log는 테스트용 임시 코드
     → 시스템이 정상 동작함을 확인한 뒤 제거할 것.
     → 제거 대상 위치:
        - DayMissionManager.cs UpdateMissions() foreach 내부
        - DayMissionManager.cs HandleMissionLost() 첫 줄
        - DayManager.cs OnDayEnd 호출 직전 줄

  ② Console에 아무 로그도 안 찍히는 경우 점검 순서
     1) [DayManager] Inspector → _missionManager 필드가 null이 아닌지 확인
     2) [DayMissionManager] 오브젝트에 DayMissionManager.cs 컴포넌트가 붙어있는지 확인
     3) Day_Default.asset의 MissionSOs 리스트에 Mission_Test.asset이 연결됐는지 확인
     4) StartDay()가 실제로 호출되는지 확인 (GameManager.NewGame() 선행 필요)

  ③ "임무 등장" 로그만 찍히고 "하루 종료" 로그가 안 찍히는 경우
     → Mission_Test.asset의 TimeToAccept가 0이면 즉시 Lost 처리되지만
       HasMissions()가 false로 전환되지 않는 버그 가능성 있음.
     → TimeToAccept를 반드시 양수(테스트 권장값: 40)로 설정할 것.
