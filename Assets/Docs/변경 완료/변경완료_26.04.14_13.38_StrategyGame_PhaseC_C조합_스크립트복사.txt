e. 작동 흐름
================================================================

  [ Phase C 기준 실행 흐름 ]

  1. 씬 시작
     → GameManager (Singleton) Awake 시 _Instance 등록
     → CharacterDatabase Awake: Resources에서 CharacterSO 로드
     → CharacterLevelDatabase Awake: PlayerLevelSO 목록 로드

  2. NewGame("길드명") 호출
     → FactoryGameState.CreateGameState() 실행
     → GameStateSO의 AvailableCharacters → CharacterUnit 생성
     → Guild, GameState 초기화

  3. DayManager.StartDay(day, characters) 호출
     → characters 전원 Available 상태로 초기화
     → DaySO에서 DayDurationInSeconds 읽어 루프 시간 결정
     → DayCharacterManager.Init(characters)
     → DayLoopCoroutine(dayDuration) 코루틴 시작

  4. DayLoop (Phase C: 미션 없는 단순 루프)
     → 매 0.5초마다 DayCharacterManager.UpdateCharacters() 호출
     → CharacterUnit.UpdateCharacter(): Resting 상태 타이머 체크
     → OnTimeUpdated 이벤트 발행
     → elapseTime >= dayDuration → 루프 종료

  5. 하루 종료
     → WaitUntil(AllCharacterInBase): 전원 Available/Resting 확인
     → OnDayEnd(DayReport) 이벤트 발행
     → GameManager.CompleteDay(dayReport) 호출 시 길드 경험치 처리

  6. 종료 시 자동 저장
     → OnApplicationQuit → SaveSystem.Save(GameStateData)
     → Application.persistentDataPath에 JSON 저장
