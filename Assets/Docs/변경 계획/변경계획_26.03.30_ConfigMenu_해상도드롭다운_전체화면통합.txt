b. 요구한 기능
----------------------------------------------------------------

  - 화면 설정을 드롭다운 하나로 통합한다.
  - 드롭다운 첫 번째 항목(index 0): "1920 x 1080 (전체화면)"
  - 드롭다운 나머지 항목(index 1~): 창모드 해상도 목록
      [1] 1920 x 1080
      [2] 1600 x 900
      [3] 1280 x 720
      [4] 1024 x 768
      [5] 800 x 600
      [6] 640 x 480
  - 전체화면/창모드를 별도 버튼 없이 드롭다운 선택만으로 처리한다.

c. 현재 상황 및 코드
----------------------------------------------------------------

  [현재 동작 방식]
  - 드롭다운: Screen.resolutions(시스템 해상도 목록)를 그대로 나열
  - 전체화면/창모드 전환: 별도 버튼으로 SetDisplayToFullScreen(bool) 호출
  - VN_Configuration에 dispaly_fullscreen(bool)과 display_resolution(string)을
    각각 독립된 필드로 저장

  [현재 코드 - VN_Configuration.cs]

    public bool dispaly_fullscreen = true;         // 전체화면 여부 별도 저장
    public string display_resolution = "1920 x 1080";

    public void Load()
    {
        var ui = ConfigMenu.instance.ui;
        ConfigMenu.instance.SetDisplayToFullScreen(dispaly_fullscreen); // 버튼용 메서드 호출
        int res_index = 0;
        for(int i = 0; i < ui.resolutions.options.Count; i++)
        {
            if(ui.resolutions.options[i].text == display_resolution)
            {
                res_index = i;
                break;
            }
        }
        ui.resolutions.value = res_index;
    }

  [현재 코드 - ConfigMenu.cs]

    private void SetAvailableResolutions()
    {
        Resolution[] resolutions = Screen.resolutions;   // 시스템 해상도 전부 나열
        List<string> options = new List<string>();
        for(int i = resolutions.Length - 1; i >= 0; i--)
            options.Add($"{resolutions[i].width} x {resolutions[i].height}");
        ui.resolutions.ClearOptions();
        ui.resolutions.AddOptions(options);
    }

    public void SetDisplayToFullScreen(bool fullscreen)  // 버튼에서 직접 호출
    {
        Screen.fullScreen = fullscreen;
    }

    public void SetDisplayResolution()
    {
        string resolution = ui.resolutions.captionText.text;
        string[] values = resolution.Split('x');
        if(int.TryParse(values[0].Trim(), out int width) && int.TryParse(values[1].Trim(), out int height))
        {
            Screen.SetResolution(width, height, Screen.fullScreen); // fullscreen 여부를 현재 상태에서 읽음
            confing.display_resolution = resolution;
        }
    }

  [문제점 요약]
  1. 드롭다운이 시스템 해상도를 나열하므로 환경마다 항목이 달라진다.
  2. 전체화면/창모드는 버튼이 별도로 존재해 조작 단계가 두 개다.
  3. dispaly_fullscreen(bool)과 display_resolution(string)이 따로 저장되어
     두 값이 불일치할 경우(예: fullscreen=true인데 해상도는 창모드 값) 버그가 생길 수 있다.

d. 요구한 기능을 만들기 위해서 어떤 식으로 추가하거나 변경해야 하는지
----------------------------------------------------------------

  [핵심 아이디어]
  드롭다운 index 0을 전체화면 전용 항목으로 고정하고,
  index 1 이상은 창모드 해상도 목록으로 구성한다.
  SetDisplayResolution()에서 index를 기준으로 전체화면/창모드를 분기한다.

  [변경 요약]

  1. ConfigMenu.cs - SetAvailableResolutions()
     - Screen.resolutions 대신 코드에 고정 목록을 직접 정의한다.
     - 목록 구성:
         index 0 → "1920 x 1080 (전체화면)"
         index 1 → "1920 x 1080"
         index 2 → "1600 x 900"
         index 3 → "1280 x 720"
         index 4 → "1024 x 768"
         index 5 → "800 x 600"
         index 6 → "640 x 480"

  2. ConfigMenu.cs - SetDisplayResolution()
     - index == 0이면 Screen.SetResolution(1920, 1080, FullScreenMode.ExclusiveFullScreen)
     - index >= 1이면 텍스트 파싱 후 Screen.SetResolution(width, height, FullScreenMode.Windowed)
     - confing.display_resolution에 현재 선택된 텍스트 그대로 저장

  3. ConfigMenu.cs - SetDisplayToFullScreen()
     - 버튼용 메서드이므로 버튼 제거 후 더 이상 불필요 → 제거

  4. VN_Configuration.cs
     - dispaly_fullscreen(bool) 필드 제거
       (드롭다운 index 0 여부로 전체화면이 결정되므로 중복 저장 불필요)
     - Load()에서 SetDisplayToFullScreen() 호출 제거
     - display_resolution 문자열로 드롭다운 index를 찾는 기존 로직은 그대로 유지

  5. Unity Scene
     - 전체화면/창모드 전환 버튼 오브젝트 제거
     - 드롭다운 OnValueChanged 이벤트에 SetDisplayResolution() 연결 확인


----------------------------------------------------------------
e. 다른 방법들 중에서 왜 d의 방식으로 만든 것인지
----------------------------------------------------------------

  [비교한 다른 방법들]

  방법 A: 드롭다운은 해상도만, 별도 Toggle로 전체화면/창모드 전환 (현재 구조와 유사)
    - 단점: 사용자가 해상도 선택 후 토글까지 추가 조작 필요 → UX 불편
    - 단점: dispaly_fullscreen + display_resolution 두 필드를 항상 함께 관리해야 함
    - 단점: 두 값이 불일치하는 버그 구조가 그대로 남음

  방법 B: Screen.resolutions 동적 목록 + 맨 앞에 전체화면 항목 삽입
    - 단점: 모니터마다 지원 해상도가 달라 드롭다운 항목 수와 순서가 환경에 따라 변동
    - 단점: 저장된 index가 다른 환경에서는 엉뚱한 해상도를 가리킬 수 있음

  [d 방식을 선택한 이유]

  1. 드롭다운 하나로 전체화면/창모드+해상도를 한 번에 선택 → UX 단순화
  2. 고정 목록이므로 모니터 환경과 무관하게 항상 동일한 항목 보장
  3. display_resolution 문자열이 표시 텍스트와 1:1 대응 → Load/Save 로직 단순
  4. dispaly_fullscreen bool 제거로 두 필드 간 불일치 버그 구조적으로 차단
  5. 변경 범위가 최소 (SetAvailableResolutions, SetDisplayResolution, Load 세 곳)

f. 어떤 순서로 진행할 것인지
----------------------------------------------------------------

  Step 1. VN_Configuration.cs 수정
    - dispaly_fullscreen 필드 제거
    - Load()에서 SetDisplayToFullScreen(dispaly_fullscreen) 호출 제거
    - display_resolution 필드 및 나머지 Load/Save 로직은 그대로 유지

  Step 2. ConfigMenu.cs 수정
    - SetAvailableResolutions(): 고정 목록으로 교체
    - SetDisplayResolution(): index 기반 전체화면/창모드 분기 처리 추가
    - SetDisplayToFullScreen(): 제거

  Step 3. Unity Scene 수정
    - 전체화면/창모드 전환 버튼 오브젝트 제거
    - 버튼 OnClick 이벤트 정리
    - 드롭다운 OnValueChanged → SetDisplayResolution() 연결 여부 확인

  Step 4. 기존 저장 파일 호환성 확인
    - vnconfig.cfg에 dispaly_fullscreen 필드가 없어지더라도
      JsonUtility는 없는 필드를 무시하므로 로드 오류 없음
    - 다만 기존 저장된 display_resolution 값이 새 목록 텍스트와 일치하는지 확인
      (예: 기존값 "1920 x 1080"은 index 1과 일치 → 정상)
      (예: 기존값에 "(전체화면)"이 없으면 index 0이 선택되지 않음 → fallback으로 index 0 설정)

  Step 5. 동작 테스트
    - 드롭다운 항목 7개(index 0~6) 정상 표시 확인
    - index 0 선택 시 전체화면 전환 확인
    - index 1~6 선택 시 각 해상도 창모드 전환 확인
    - 설정 저장 후 재시작 시 올바른 항목이 선택되어 있는지 확인

g. 어디가 어떤 식으로 변경되는지
----------------------------------------------------------------

  [ 파일: VN_Configuration.cs ]

    (제거) dispaly_fullscreen 필드
      Before: public bool dispaly_fullscreen = true;
      After:  (삭제)
      이유: 드롭다운 index 0 여부로 전체화면이 결정되므로 별도 저장 불필요

    (변경) Load() 내부
      Before:
        ConfigMenu.instance.SetDisplayToFullScreen(dispaly_fullscreen);
        int res_index = 0;
        for(int i = 0; i < ui.resolutions.options.Count; i++) { ... }
        ui.resolutions.value = res_index;

      After:
        int res_index = 0;
        for(int i = 0; i < ui.resolutions.options.Count; i++) { ... }
        ui.resolutions.value = res_index;
        // SetDisplayToFullScreen 호출 제거
        // OnValueChanged가 연결되어 있지 않은 경우 마지막에 SetDisplayResolution() 직접 호출 추가


  [ 파일: ConfigMenu.cs ]

    (변경) SetAvailableResolutions()
      Before:
        Resolution[] resolutions = Screen.resolutions;
        List<string> options = new List<string>();
        for(int i = resolutions.Length - 1; i >= 0; i--)
            options.Add($"{resolutions[i].width} x {resolutions[i].height}");

      After:
        List<string> options = new List<string>()
        {
            "1920 x 1080 (전체화면)",
            "1920 x 1080",
            "1600 x 900",
            "1280 x 720",
            "1024 x 768",
            "800 x 600",
            "640 x 480"
        };

    (변경) SetDisplayResolution()
      Before:
        string resolution = ui.resolutions.captionText.text;
        string[] values = resolution.Split('x');
        Screen.SetResolution(width, height, Screen.fullScreen);
        confing.display_resolution = resolution;

      After:
        int index = ui.resolutions.value;
        if (index == 0)
        {
            Screen.SetResolution(1920, 1080, FullScreenMode.ExclusiveFullScreen);
        }
        else
        {
            string resolution = ui.resolutions.captionText.text;
            string[] values = resolution.Split('x');
            if(int.TryParse(values[0].Trim(), out int width) && int.TryParse(values[1].Trim(), out int height))
                Screen.SetResolution(width, height, FullScreenMode.Windowed);
        }
        confing.display_resolution = ui.resolutions.captionText.text;

    (제거) SetDisplayToFullScreen(bool fullscreen)
      Before: public void SetDisplayToFullScreen(bool fullscreen) { Screen.fullScreen = fullscreen; }
      After:  (삭제)
      이유: 버튼 제거 후 외부에서 호출되는 곳이 없으므로 불필요


  [ Unity Scene: VisualNovel.unity / ConfigMenu Inspector ]

    - 전체화면 버튼 오브젝트 → 제거
    - 창모드 버튼 오브젝트 → 제거
    - 버튼 OnClick 이벤트에 연결된 SetDisplayToFullScreen 참조 → 정리
    - 드롭다운 OnValueChanged → SetDisplayResolution() 연결 확인 및 추가
